## 一、为什么需要 Git 仓库

**预指导轮次**的表单只要求「网盘 zip + 介绍文档 + B 站视频」，当时确实不需要 Git 仓库（本仓库 2026-10-30 的提交 `85f13a1` 记录了这一结论）。
但**省赛/国赛赛项章程**明确列出了四类材料，第一项就是代码仓库：

| 材料 | 官方要求 | 本项目对应 |
| --- | --- | --- |
| **代码仓库** | 托管平台 **GitHub / Gitee**，须设为 **Public** 或提供评审访问权限 | 见本指引第三节发布 |
| 代码规范 | 结构清晰、有效注释、主流规范 | 前后端分层、统一 `feat/fix/docs` 提交前缀、AI 层与业务层解耦 |
| README | 项目介绍、技术架构、安装运行指南、团队信息 | 仓库根 `README.md`（团队信息需提交前替换占位） |
| Git 记录 | **保留完整提交历史，体现真实开发过程** | 46+ 次真实提交，自 2026-09-26 起，见 `docs/GIT_HISTORY.txt` |
| 环境配置 | 完整说明（含环境变量模板、依赖清单） | `.env.example` + `docs/环境配置说明.md` + `docs/DEPLOY.md` |
| 演示视频 | 5–8 分钟、MP4、≥1080p、普通话 | `智途AI-演示视频-优化版.mp4`（上传 B站/抖音后填链接） |
| 技术文档 | PDF ≤ 30 页 | `智途AI-技术文档.pdf` |
| 在线演示（可选加分） | 公网可访问地址 + 评审体验账号 | 便携版可零安装复现；如部署公网，把地址与 `13800000000/123456` 一并附上 |

> ⚠️ **表单第 5 项仍写的是「网盘链接」**（截图原文：上传至百度网盘 / 夸克网盘 / 阿里云盘等主流网盘）。因此**两条都交最稳**：网盘 zip 按表单填；Public 仓库地址写在介绍文档 PDF、网盘包内《提交与使用说明》以及表单允许填备注的位置。切勿只填仓库链接而漏掉网盘链接。

## 三、把仓库发布为 Public（二选一）

### A. 推荐：Gitee（国内速度快，一次推送更稳）

1. 登录 <https://gitee.com> → 右上角「+」→「新建仓库」。
2. 仓库名填 `zhitu-ai`，**可见性选「公开」**。
3. **不要**勾选「使用 Readme 初始化」「选择 .gitignore」「选择开源许可证」——必须创建**空仓库**，否则推送会被拒绝。
4. 创建后复制 HTTPS 地址，形如 `https://gitee.com/你的用户名/zhitu-ai.git`。
5. 解压 `智途AI-Git仓库-可直接推送.zip`（**这个包才含 `.git`**，提交版 zip 不含），进入 `scripts/`，双击 `publish-repo.bat`（纯 ASCII，任何代码页都不乱码），粘贴地址回车。
6. 首次推送会弹出登录框：Gitee 用账号 + 私人令牌（设置 → 私人令牌）；GitHub 用用户名 + **Personal Access Token**（密码框不接受账户密码）。

### B. GitHub

步骤同上，地址形如 `https://github.com/你的用户名/zhitu-ai.git`，可见性选 **Public**。国内网络若推送超时，可改用 Gitee，或配置代理后重试。

### 命令行等价操作

```bash
cd zhitu-ai                 # 必须是含 .git 的目录
git remote add origin https://gitee.com/你的用户名/zhitu-ai.git
git branch -M main
git push -u origin main
```

Linux / macOS 可用 `scripts/publish-repo.sh`（`bash scripts/publish-repo.sh`）。

### 离线备份（可选）

`智途AI-源码仓库.bundle` 是含**全部提交历史**的 Git 打包文件，可离线保存或恢复：

```bash
git clone zhituAI-source.bundle zhitu-ai
cd zhitu-ai && git remote add origin <你的仓库地址> && git push -u origin main
```

## 五、常见问题

| 现象 | 处理 |
| --- | --- |
| `error: failed to push some refs` | 远程仓库被初始化了 README/license。删掉重建空仓库，或先 `git pull --rebase origin main` 合并 |
| 提示 `Authentication failed` | GitHub 必须用 Personal Access Token 当密码；Gitee 用账号 + 私人令牌 |
| 推送很慢 / 超时 | 历史中曾有 `node_modules`（已在第 7 次提交移除），首次推送约 70 MB；优先 Gitee 或稳定网络 |
| `fatal: not a git repository` | 解压的是提交版 zip（不含 `.git`）。改用 `智途AI-Git仓库-可直接推送.zip` 或从 bundle clone |
| 想改仓库地址 | 重新双击 `publish-repo.bat`，脚本会先移除旧 `origin` 再添加新地址 |
| 中文 bat 乱码 | 用 `publish-repo.bat`（纯 ASCII）即可，不要另存为 UTF-8 |
