智途AI —— 一体化演示版 使用说明
==================================================

【这是什么】
将前端、后端、数据库打包成单个 jar 的便携版本。
对方电脑无需安装 MySQL、Node.js、Maven，
只要装有 JDK 8 或更高版本（推荐 JDK 17）即可双击运行。

【运行方法】
1. 确认电脑已装 Java（命令行执行 java -version 查看）
   未安装可用一键命令：winget install EclipseAdoptium.Temurin.17.JDK
2. 双击「启动智途AI.bat」（或直接双击 zhitu-ai.jar 也可以）
3. 等待 5-10 秒，浏览器自动打开 http://localhost:8080
4. 关闭黑色命令行窗口即停止服务

【AI 能力：三分钟看懂】
本作品的 AI 是一个会自己查数据的成长 Agent，而不是聊天框：

1. 在「AI助手」页直接问"我这个专业该参加哪些竞赛？"
2. 回答过程中会显示它在做什么：检索知识库 -> 调用工具 -> 整合资料
3. 回答下方展开「查看依据」，可以看到：
   - 它调用了哪些工具，每个工具返回了什么真实数据
   - 本次参考了哪些知识库片段（带相关度评分）
   - 事实校验结果：回答里的信息是否都能在上面找到出处

也就是说，AI 给出的每一个具体建议，都能追溯到数据库里的真实记录。

【关于 API Key】
- 不填 Key 也能完整演示：工具照样真实执行，数据照样来自数据库，
  页面上会明确标注「离线模板模式」，不会把模板结果伪装成 AI 生成。
- 想看真实大模型效果：登录后进入「API设置」，填入任意兼容
  OpenAI Chat Completions 协议的 Key 即可（DeepSeek / 通义千问等）。

【新增：B站课堂】
- 登录后顶部导航「B站课堂」：41 门大学生口碑公开课，按你的专业严格匹配推荐（不对口的课程不会出现）
  （专业对口 100 分 / 同方向 80 分 / 通用 60 分），每条标注推荐理由
- 链接为"课程名+UP主"的 B 站搜索直达，不会因视频下架失效
- 在 AI 助手问"高数去哪学"，AI 会调用 search_bilibili_courses 工具返回链接，可在「查看依据」中溯源

【其他能力的入口】
- 证书 / 奖状拍照自动录入：成长档案页上方「选择图片」
- 语音提问与朗读回答：AI助手页输入框左侧的麦克风与喇叭按钮
- MCP 工具清单：登录后访问 /api/agent/tools

【数据说明】
- 使用内置 H2 数据库，首次启动自动建表并导入基础数据
  （175 个专业 / 3900+ 门课程 / 101 场竞赛 / 41 门 B 站精选公开课 / 15 篇方法语料）
- 注册用户、档案、规划等数据保存在本目录的 data 文件夹，重启不丢失
- 如需清空重来：停止服务后删除 data 文件夹，再启动即可

【常见问题】
- 浏览器打开显示无法连接：启动需要几秒，稍等刷新即可
- 8080 端口被占用：在命令行执行 java -jar zhitu-ai.jar --server.port=8090 换端口启动，或关闭占用 8080 的程序
- Mac / Linux 用户：无需 bat，命令行执行 java -jar zhitu-ai.jar 即可
- 必须先完整解压再运行，不要在压缩软件窗口里直接双击 bat
