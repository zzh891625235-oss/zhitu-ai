智途AI —— 一体化演示版 使用说明
==================================================

【这是什么 / 换一台电脑能用吗】
将前端、后端、数据库打包成单个 jar 的便携版本，不绑定任何一台机器。
换任何一台电脑都能运行：不需要 MySQL、Node.js、Maven、数据库配置或 API Key，
唯一前提是装有 Java：8 / 11 / 17 / 21 均可（已实测 8、17、21 启动成功，推荐 JDK 17），Java 7 及以下不行。
包里不含 data 数据库目录，新电脑首次启动会自己建一份干净的演示库；
因此你在原电脑上新增的账号、打卡等数据不会跟着带走（正常行为，不是出错）。

【运行方法】
1. 完整解压 zip，再运行（不要在压缩软件窗口里直接双击 bat）
2. 确认已装 Java：命令行执行 java -version
   8 / 11 / 17 / 21 都能跑，不用切换 JDK，装 JRE 也行；
   只要求有 java 命令，不要求完整 JDK，Java 7 及以下不行。
   没装也不用慌：启动脚本会给出明确提示，不会闪退。
   Windows 一键安装：winget install EclipseAdoptium.Temurin.17.JDK
   装完请重新打开命令行窗口 / 重新双击 bat 才会生效
3. 双击「启动智途AI.bat」（Mac / Linux 执行 java -jar zhitu-ai.jar）
4. 等待 5-10 秒，浏览器自动打开 http://localhost:8080
   若 8080 已被占用，脚本会自动改用 8090，以黑窗口显示的地址为准
5. 关闭黑色命令行窗口即停止服务

【AI 能力：三分钟看懂】
本作品的 AI 是一个会自己查数据的成长 Agent，而不是聊天框：

1. 在「AI助手」页直接问"我这个专业该参加哪些竞赛？"
2. 回答过程中会显示它在做什么：检索知识库 -> 调用工具 -> 整合资料
3. 回答下方展开「查看依据」，可以看到：
   - 它调用了哪些工具，每个工具返回了什么真实数据
   - 本次参考了哪些知识库片段（带相关度评分）
   - 事实校验结果：回答里的信息是否都能在上面找到出处

也就是说，AI 给出的每一个具体建议，都能追溯到数据库里的真实记录。

【关于 API Key】
- 不填 Key 也能完整演示：工具照样真实执行，数据照样来自数据库，
  页面上会明确标注「离线模板模式」，不会把模板结果伪装成 AI 生成。
- 想看真实大模型效果：登录后进入「API设置」，填入任意兼容
  OpenAI Chat Completions 协议的 Key 即可（DeepSeek / 通义千问等）。

【常见问题】
- 浏览器打开显示无法连接：启动需要几秒，稍等刷新即可；若窗口提示端口已改为 8090，请访问 8090
- 8080 端口被占用：启动脚本会自动改用 8090；也可手动指定
  java -jar zhitu-ai.jar --server.port=8090
- 双击没反应 / 提示找不到 Java：执行 java -version 检查；未安装按上面第 2 步装 JDK，
  安装完成后必须重新打开窗口再运行
- Mac / Linux 用户：无需 bat，命令行执行 java -jar zhitu-ai.jar 即可
- 必须先完整解压再运行，不要在压缩软件窗口里直接双击 bat


【启动脚本出现乱码 / 一堆「不是内部或外部命令」】
现象：'errorlevel' 不是内部或外部命令、'files.active' 不是内部或外部命令、
'DK' 不是内部或外部命令，中文显示成「曞惎鍔ㄣ€」之类乱码。
原因：cmd.exe 按 GBK（代码页 936）读取 bat，脚本若被存成 UTF-8，
中文会变成乱码并把 if、echo. 等命令吞掉，剩下的单词被当成命令执行。
这不是程序坏了，jar 本身完全正常。
处理：
1. 包内 bat 已统一保存为 ANSI/GBK 编码，直接双击即可；
   不要用编辑器打开后「另存为 UTF-8」。
2. 若中文仍乱码（例如系统开了 UTF-8 全球语言支持），
   改用同目录的 start-en.bat（纯 ASCII 英文脚本，任何代码页都能跑，
   启动后浏览器界面仍是中文）。
3. 也可完全绕开 bat，在便携版目录执行：
   java -jar zhitu-ai.jar --spring.profiles.active=demo --server.port=8080
4. 必须先完整解压，确认 zhitu-ai.jar 与 bat 在同一文件夹。
